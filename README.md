# Loja Veloz – Cloud DevOps

Projeto acadêmico de uma plataforma de pedidos
baseada em microsserviços.

## Tecnologias
- Java
- Spring Boot
- PostgreSQL
- Docker e Docker Compose
- Kubernetes
- GitHub Actions
- Terraform

## Objetivo
Desenvolver uma aplicação com microsserviços,
automatização de processos, escalabilidade
e monitoramento.
